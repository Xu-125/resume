# Career Asset & Resume System

将零散工作记录转化为可检索、可验证、可复用的职业资产，并持续维护简历。默认使用用户提供的事实；不编造数据、职责、影响或技能。

## 文件组织

优先在用户指定目录工作；没有指定时使用当前项目的 `career-assets/`：

```text
career-assets/
├── profile.md                 # 长期职业定位、能力地图、求职偏好
├── experience-bank.md         # 经历与成果库，按项目/岗位沉淀
├── evidence-ledger.md         # 成果证据、指标、来源与可信度
├── reflections/               # 日/周/月反思
│   └── YYYY-MM-DD.md
├── daily-assets/              # 每日工作资产
│   └── YYYY-MM-DD.md
├── resumes/                   # 基础简历与岗位版本
│   ├── master-resume.md
│   └── tailored/
└── jds/                      # 保存过的 JD 与解析
```

## 工作模式

### 1. 每日经历梳理

当用户记录当天工作时：

1. 先读取已有 `profile.md`、近期 `daily-assets/` 和相关 `experience-bank.md` 条目，避免重复提问。
2. 用最少问题补齐：做了什么、为什么做、具体产出、解决了什么问题、影响/指标、协作对象、难点与决策、可复用方法。
3. 将原始事实与推断分开；缺失指标标记为“待补证据”，不要估算成事实。
4. 输出并保存“今日工作资产”，至少包含：事实摘要、成果表达、能力标签、证据、可迁移经验、待跟进问题、简历可用性。
5. 将高价值成果去重合并到 `experience-bank.md`，保留日期和来源。

每日资产模板见 [daily-asset-template.md](references/daily-asset-template.md)。

### 2. 固定工作反思

完成每日梳理后，固定进行轻量反思：

- 今天最重要的结果是什么？
- 哪个判断、方法或协作产生了价值？
- 哪里卡住、返工或低效？根因是什么？
- 明天一个最小改进动作是什么？
- 这件事说明了我的哪项能力，能否迁移到其他场景？

按日写入 `reflections/YYYY-MM-DD.md`。用户要求周/月复盘时，汇总周期内资产，识别重复出现的能力、成果趋势、短板和下一阶段行动，不把反思直接当作简历事实。

### 3. 整体职业经历与简历梳理

当用户要求梳理完整经历或更新主简历时：

1. 读取所有可用材料和 `experience-bank.md`。
2. 按岗位/项目重建时间线，识别职责、关键行动、结果、能力和证据。
3. 区分“做过的事”“做成的事”“可证明的影响”，优先使用结果导向表达。
4. 更新 `profile.md`、`experience-bank.md` 和 `resumes/master-resume.md`，保留变更说明。
5. 对每条简历 bullet 做真实性检查：行动 + 对象/范围 + 方法 + 结果/指标；没有结果时明确标注需要补充。

详细提炼规则见 [experience-method.md](references/experience-method.md)。

### 4. 针对 JD 定制简历

当用户提供 JD 或岗位链接时：

1. 保存 JD 到 `jds/`，提取岗位目标、关键职责、硬技能、软技能、行业语境和隐含筛选词。
2. 将 JD 要求与经历库逐条匹配，标记强匹配、可迁移匹配、证据不足和真实缺口。
3. 只从真实经历中重排、压缩、改写和强调；不得为了关键词虚构经历。
4. 生成 `resumes/tailored/{company}-{role}.md`，包含：定位摘要、精选技能、相关经历、项目/成果、匹配说明和未覆盖要求。
5. 给出简历更新建议：应补充的指标、应删减的内容、需要向用户追问的证据、推荐的标题/摘要和 ATS 风险。
6. 若用户确认，才将新事实回写经历库；岗位专属措辞不能污染主简历。

JD 匹配与 bullet 规则见 [resume-rules.md](references/resume-rules.md)。

## 输出要求

每次完成后简洁报告：本次新增资产、更新了哪些文件、可直接写进简历的 1–3 条表达、尚待补证据的问题、下一步建议。若没有足够事实，先输出结构化待补问题，不代写虚假成果。

## 触发词与快捷请求

支持自然语言，也支持以下意图：

- “记录今天工作 / 今日工作资产” → 每日梳理
- “复盘今天 / 做周复盘” → 反思
- “梳理我的经历 / 更新主简历” → 职业资产与主简历
- “根据这个 JD 改简历” → JD 定制
- “这段经历能不能写进简历” → 事实核验与 bullet 建议
