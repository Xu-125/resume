# 职业资产与简历系统 · Career Asset & Resume System

**把每日做过的事，整理成可追溯的经历库，再按岗位要求写简历。**

适合工作记录分散、需要定期复盘，或正在准备不同岗位求职材料的人。这个仓库提供 Agent Skill 和参考模板，不是个人简历文件，也不自带应用或后台服务。

## 可以完成什么

- **记录工作**：梳理行动、产出与证据，保存每日工作资产。
- **沉淀经历**：把高价值成果去重合并到经历库，保留日期与来源。
- **维护简历**：区分职责、成果与可证明的影响，更新基础简历。
- **匹配岗位**：结合 JD 从真实经历中筛选、重排和改写，不虚构技能或指标。

## 安装

下载或克隆仓库后，把 `career-asset-resume-system/` **完整文件夹**导入支持 Agent Skills 的工具，保留 `SKILL.md`、`references/` 和 `agents/` 的相对位置。安装入口以所用工具为准。

```bash
git clone https://github.com/Xu-125/resume.git
```

## 试用

```text
这是我今天的工作记录。帮我整理今日工作资产，标出哪些能写进简历、哪些还需要证据。
```

```text
根据这个岗位 JD，从我的经历库里挑选相关成果，整理一版简历。没有证据的指标不要补写。
```

## 使用条件

Agent 需要能读写你授权的文件，并读取你提供的工作记录、已有简历与岗位材料。新信息回写经历库前需要核对；缺少数据时标记待补证据，不把反思或推测当作成果事实。

默认维护目录与各模式的详细规则见 [SKILL.md](career-asset-resume-system/SKILL.md)。

## 隐私

个人工作记录、公司内部材料、联系方式和定制简历保存在自己的授权目录，不要提交到本公开仓库。公开的是方法与模板，不是使用者的职业档案。
